# ReactomePA: pathway analysis and visualization

**Primary publication:**(https://doi.org/10.1039/C5MB00663E)

ReactomePA connects high-throughput molecular results to the manually curated Reactome pathway
database. It supports over-representation analysis with a hypergeometric test and ranked-list
gene set enrichment analysis.

The package can also analyze genomic regions, including regulatory and non-coding regions, by
linking them to functional annotations. It supports comparisons across experiments and provides
customizable visualizations for enriched pathways and their relationships.

The publisher does not provide an open full-text article through Europe PMC. This document
therefore summarizes the indexed abstract only. Use [reference.md](reference.md) for the current
API and the [clusterProfiler book](../clusterProfiler/book.md) for the maintained workflow.
